# Assets

Drop the following files in this folder. All images should be optimized
(under 300KB each ideally). Use https://squoosh.app to compress.

| File | Size | Purpose |
|---|---|---|
| `favicon.png` | 32×32 | Browser tab icon |
| `apple-touch-icon.png` | 180×180 | iOS home screen icon |
| `og-image.jpg` | 1200×630 | Social share preview (Facebook, Twitter, etc.) |
| `hero-product.jpg` | 800×1000 | Main hero product photo (4:5 ratio) |
| `featured-main.jpg` | 1000×1000 | Featured product detail photo (1:1 ratio) |
| `product-1.jpg` … `product-6.jpg` | 600×600 | Gallery product photos (1:1 ratio) |

## Tips
- Shoot products against a clean dark background to match the site aesthetic
- Use consistent lighting/angle across the gallery for a cohesive look
- The `og-image.jpg` should include your brand name and a strong product photo
